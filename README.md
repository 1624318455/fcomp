# FComp - 文件比对工具

> 轻量、快速、零依赖的在线文件比对工具。无需构建、无需安装，浏览器打开即用。

**在线地址**: [https://fcomp.vercel.app](https://fcomp.vercel.app)

## 功能

| 功能 | 说明 |
|------|------|
| 工具栏 | Split/Unified视图切换、隐藏相同行、自动换行、导出差异报告 |
| 暗色主题 | 完整暗色主题支持，偏好自动持久化到本地存储 |
| Unified视图 | 单栏内联差异展示，+/-标记和双列行号，适合长文件对比 |
| 差异导出 | 将差异报告导出为 .txt 文件，方便分享和存档 |
| 隐藏相同行 | 过滤掉未变化行，聚焦差异内容，Split/Unified均支持 |
| 自动换行 | 切换 pre/pre-wrap，适应长行代码或宽内容 |
| 文件上传 | 拖放或点击选择文件，支持 .txt/.js/.json/.html/.css/.md 等文本格式 |
| 文本粘贴 | 支持直接粘贴文本内容进行比对 |
| 行级比对 | 基于 jsdiff 的行级差异分析，新增/删除/修改行颜色区分 |
| 词级高亮 | 修改行内精确标出变化的词（内联高亮） |
| 行号 Gutter | 左右面板均显示行号，差异行带颜色标记 |
| 同步滚动 | 左右面板同步滚动，开启/关闭可切换 |
| 差异详情面板 | 底部可拖拽调整大小的面板，展示完整差异列表 |
| 差异跳转 | 点击差异项跳转到对应行并高亮 |
| 统计概览 | 总计/新增/删除/修改数量一目了然 |
| 文件校验 | 10MB 大小限制 + 文件类型白名单 |
| 确认保护 | 清空操作需二次确认，防止误操作 |

## 技术栈

- **语言**: HTML + CSS + Vanilla JavaScript
- **比对引擎**: [jsdiff](https://github.com/kpdecker/jsdiff) 8.0.2（CDN 引入）
- **构建**: 无，直接打开 `index.html` 即可开发/使用
- **部署**: Vercel 静态托管
- **测试**: Playwright MCP（待配置）

## 快速开始

```bash
# 本地开发：直接打开
start index.html

# 部署（推送 master 后 Vercel 自动部署）
git push
```

## 项目结构

```
fcomp/
├── index.html              # 入口页面（单页应用）
├── css/
│   └── styles.css          # 全部样式（CSS 变量设计系统）
├── js/
│   ├── main.js             # 主入口：初始化、事件绑定、全局状态
│   ├── file-handler.js     # 文件模块：上传/读取/编码/验证
│   ├── diff-engine.js      # 比对引擎：行级/词级差异分析
│   ├── ui-renderer.js      # UI 渲染：差异行/统计/摘要列表
│   └── scroll-sync.js      # 同步滚动：左右面板双向同步
├── docs/                   # 设计文档
├── CHANGELOG.md            # 变更日志
└── vercel.json             # Vercel 部署配置
```

## 使用流程

1. 在左侧面板上传/粘贴"原始文件"
2. 在右侧面板上传/粘贴"比较文件"
3. 点击"开始比对"
4. 在底部差异面板查看结果，点击差异项跳转定位

## 设计原则

- **零构建**：直接打开 `index.html` 即可开发，适合快速迭代
- **CSS 变量设计系统**：`styles.css` 顶部 `:root` 定义所有颜色/间距/阴影
- **安全优先**：所有用户内容渲染前通过 `escapeHtml()` 防 XSS
- **IIFE 模块模式**：非 ES Module，通过 `<script>` 标签按序加载
